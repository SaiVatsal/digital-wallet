# Project 56: Digital Wallet App (VoltPay)

A decentralized fintech digital wallet and neo-banking platform built with **React 18 + Vite 5 + Tailwind CSS 3.4 + Zustand 4.5**.

## Features
- **Monospace Liquid Balance & Vault**: Instant multi-currency display with 5.2% APY savings vault.
- **P2P Fast Transfers**: Send money by @cashtag with note tags and instant settlement.
- **Dynamic Virtual & Physical Cards**: Card freeze/unfreeze controls, CVV reveal, and contactless limits.
- **Scan-to-Pay QR Generator**: Interactive invoice and personalized QR codes.
- **Scheduled Bill Pay & Utilities**: Autopay toggles for electric, internet, and subscriptions.
- **Categorized Spend Telemetry**: Monthly budget progress and categorized spending analytics.
